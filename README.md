# 技術釣り LP

技術釣りを紹介する、ゲーム本体とは独立したスクロール体験の企画・制作リポジトリです。

## コンセプト

海面から垂れた一本の釣り糸をたどり、スクロールで水中へ降りていく。水面の風紋が潮の流れへ変わり、光が弱まるにつれて魚の気配から姿が現れます。魚の動きで技術ごとの個性を見せ、最後に実際のゲームへ案内します。

## いま決まっていること

- ゲーム本体とは別の作品・別リポジトリとして作る。
- LPは静的サイトを基本にし、DB・ゲームAPI・WebSocketは持たない。
- 技術候補はAstro + TypeScript。本文は静的HTMLを中心にし、必要なら水中の3Dだけを独立して読み込む。
- スクロールは通常動作のまま。動きは`prefers-reduced-motion`に対応し、3Dなしでも内容とゲーム導線が成立する。
- ハッカソン後に本格制作する。現段階では企画と最小の骨格のみ。

技術釣りの魚は技術概念を伝えるための表現であり、各技術の仕組みをそのまま再現するシミュレーターではありません。

## 体験の流れ

海面で作品の内容と「ゲームを始める」導線を見せる → 糸をたどって水面下へ → 気配・影から魚を段階的に見せる → 魚の動きと技術の対応を短く伝える → ゲーム本編へ案内する。

初期案ではGo魚・Dockerクジラ・CSS fishを扱います。K8sレヴィアタンは実験的な魚種なので、通常の紹介に含めるかは別途判断します。
